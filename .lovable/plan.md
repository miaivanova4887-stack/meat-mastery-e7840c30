

## Update Android App Name to "CarnivoreX"

The `android/` directory does not exist in the Lovable project repository — it is generated at build time by `npx cap sync android` (as seen in `scripts/build-android-fresh.sh`). The `strings.xml` file is auto-generated by Capacitor from `capacitor.config.json`.

### What to change

**`capacitor.config.json`** — update the `appName` field to `"CarnivoreX"`. This is the source of truth that Capacitor uses to generate `android/app/src/main/res/values/strings.xml` (including `app_name` and `title_activity_main`).

### What not to change
- `appId` (package ID) — stays as-is
- `webDir`, `server`, `plugins` — untouched
- No other config files affected

### After implementation
Run `scripts/build-android-fresh.sh` on your local machine — the sync step will regenerate `strings.xml` with the new name.
